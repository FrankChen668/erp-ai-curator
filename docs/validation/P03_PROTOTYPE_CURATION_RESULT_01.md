## Why invalidated

The retained sprint result did not preserve a trustworthy evidence chain:

- several practitioner sources were named but concrete URLs/citations proving acquisition and reading were not retained;
- current Tool capability claims were written without traceable current-fact sources;
- source discovery, actual content reading and model synthesis cannot be reliably distinguished after the fact;
- therefore the prior recommendation cannot be audited to the standard used by accepted P04/P06 evidence.

A plausible conclusion is not enough to close a card.

## What is not currently established

- coded prototype is the generic ERP/B-end default;
- Figma Make is preferred whenever a Figma design system exists;
- v0 / AI IDE / coding Agent is the default P03 implementation path;

These may later be supported, modified or rejected by a trustworthy rerun.

Required evidence discipline:

2. retain concrete source URLs;

6. record limitations/counter-evidence;

8. close only when an auditable recommendation is stable.
